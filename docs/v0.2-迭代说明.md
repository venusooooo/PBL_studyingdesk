# v0.2 迭代说明

> 记录这一版"从框架到能用"做了什么、为什么这么做、怎么验证的，方便写进 PBL 报告。

## 一、这一版要解决的问题

v0.1 交付的是四个区域 + 七个占位页，导航能点、页面能切，但**没有任何数据**，也没有存储层。
本版的目标是把它变成一个真正能用的学习管理工具，所以先补齐三件底层的事，再逐个模块填业务：

1. 数据模型（课程 / 课时 / 错题 / 笔记 / 任务 / 计划 / 专注记录）
2. 数据仓库 `Store`：CRUD + 本地持久化 + 变更通知
3. 页面刷新机制：进入页面自动重画，保证跨模块改动能立刻看到

## 二、为什么这么设计

| 决策 | 原因 |
| --- | --- |
| 所有页面共用一个 `Store` 单例 | 数据量是"一个人的学习记录"，千级以内，没必要上 SQLite；单例最省事，也避免了各页面各自读文件导致的不一致 |
| 自己写 200 行 JSON 读写，不引第三方库 | 课程要求零依赖、`javac` 直接编译；JSON 又比 Java 序列化可读、可手工修、可进版本库对比 |
| 每次改动都立即落盘 | 桌面小工具没必要做"显式保存"，用户关窗口就丢数据是最大的信任伤害 |
| 计划进度不存字段，实时算 | 进度是任务的派生量，存下来一定会和任务状态不同步 |
| 复习间隔固定为 1/2/4/7/15/30 天 | 艾宾浩斯曲线的简化版，规则写在 `Store.REVIEW_INTERVALS`，想调只改一处 |
| 页面进一次重画一次 | 比事件订阅简单，且天然避免"别的页面改了数据、这页还是旧的"这类问题 |

## 三、数据模型

| 实体 | 关键字段 | 说明 |
| --- | --- | --- |
| `Course` | name, teacher, color, note | 归类依据；删除时级联删除课时，其余实体降级为"未归类" |
| `Lesson` | courseId, weekday(1-7), startSlot, endSlot, room | 课表格子；保存前校验同一星期的时间块是否重叠 |
| `Exercise` | title, content, answer, reason, mastery(0/1/2), reviewCount, nextReview | 复习算法只改 nextReview 与 mastery |
| `Note` | title, content, tags, pinned, updatedAt | 置顶优先、再按更新时间倒序 |
| `Task` | title, courseId, due, priority(0/1/2), done, estimateMin, planId | `planId` 用于聚合计划进度 |
| `Plan` | title, startDate, endDate, description | 进度 = 已完成 / 关联任务数 |
| `FocusRecord` | date, minutes, label | 番茄钟每完成一次写一条，用于今日 / 本周统计 |

存储结构（`data.json`）：

```json
{
  "version": 1,
  "seq": 42,
  "termStart": "2026-11-09",
  "courses": [ { "id": 2, "name": "Java 程序设计", "color": "#2F6FED", ... } ],
  "lessons": [ ... ], "exercises": [ ... ], "notes": [ ... ],
  "tasks": [ ... ], "plans": [ ... ], "focus": [ ... ]
}
```

`seq` 是全局自增主键，避免每个实体各维护一套 id 逻辑。

## 四、功能清单与验收方式

| 模块 | 已实现 | 验收方式 |
| --- | --- | --- |
| 今日面板 | 今日课程、待办勾选、待复习错题、番茄钟、四项统计 | 勾选任务后统计与列表同步；番茄钟归零后"今日专注 +25 分钟" |
| 课表 | 7×10 周视图、点格新增、点课时编辑、右键删除、冲突校验 | 在周三第 3 节已有课的情况下再加一节 3-4 节，应弹"时间冲突" |
| 课程 | 增删改、主题色、四项数量统计、删课级联 | 删掉 Java 课后课表对应课时消失，错题/笔记变成"未归类" |
| 错题 | 录入、筛选、搜索、复习弹窗 | 点"记住了"后复习次数 +1、下次复习日期按 1/2/4/7 天递进；三次后变"已掌握" |
| 笔记 | 增删改、标签、置顶、搜索 | 置顶笔记排在最前；搜索"集合"只剩命中项 |
| 计划任务 | 计划进度条、四个视图、优先级、截止日 | 勾选任务后计划进度条立刻变化 |
| 设置 | 数据路径、立即保存、学期起始日、CSV 导出、清空/恢复 | 改学期起始日后顶部"第 N 周"跟着变 |

自动化冒烟（开发期用临时脚本跑的）：

- `Store` 增删改查 + 复习调度 + 两次进程启动验证 JSON 往返一致；
- 界面：七个页面逐页离屏渲染，检查是否有横向滚动条、控件被截断；
- 链路：依次执行"新建课程 → 新建任务 → 勾选完成 → 复习一次"，断言实体数量与字段变化正确。

## 五、踩到的坑

1. **CardLayout 把整页撑宽**：`CardLayout.getPreferredSize()` 取所有卡片的**最大值**，只要有一页内容宽 1358px，其余页面就都会出现横向滚动条、右侧按钮被截断。解决办法是让内容宿主实现 `Scrollable` 并让宽度跟随视口（`MainFrame.PageHost`）。
2. **`BoxLayout` 会按 `alignmentX` 居中子组件**：任务标题和标签莫名其妙跑到行中间。改成 `BorderLayout` + 明确的左/右区域。
3. **`BorderLayout.EAST` 会纵向拉伸控件**：圆角标签被拉成一条竖条。用 `Ui.alignRight()` 包一层 FlowLayout 固定自然高度。
4. **中文源码编译**：Windows 终端默认 GBK，必须 `-encoding UTF-8`，否则中文注释变成乱码警告。
5. **持久化要防呆**：JSON 解析失败时先备份 `data.broken.bak` 再重建，宁可多一个备份文件，也不能静默清空用户的记录。

## 七、v0.2.1 补充：打包成"能直接交付"的版本

核心功能做完后，为了让程序能脱离 IDE 独立运行，又补了三件事。

**1. 三个启动入口**

| 方式 | 入口 | 说明 |
| --- | --- | --- |
| 一键启动 | `start.bat` | 首次运行自动编译 + 打包，然后启动；之后再点就是秒开 |
| 手工构建 | `build.bat` | 等价于 `javac` + `jar` 两条命令，失败会停下来提示 |
| 免安装 exe | `dist/StudyDesk/StudyDesk.exe` | 用 `jpackage` 把程序和精简 JRE 打进一个文件夹，约 120 MB，目标机器不需要装 Java |

`jpackage --type app-image` 不需要 WiX 等额外工具链，产物是一个目录而不是安装包，正好适合"拷进 U 盘就能交作业"的场景。

**2. 这一轮修掉的界面问题**

- 顶栏"AI 关闭"按钮被压成 `AI 关...`：`JToggleButton` 默认内边距太窄，显式给 `Margin` 和 `PreferredSize`。
- 课表格子里的课程名被硬截断：改成按像素宽度裁剪并加省略号（`fit()` + `FontMetrics`），字号从 12 收到 11，格宽从 88 提到 92。
- 课表格子高度和空行高度不一致，行的下沿留白：统一为 48px。
- 今日面板的课程行原本是两行（课程名 → 地点缩进换行），显得松垮：改成单行三区（节次 / 课程 / 地点），行高锁死 34px，并在卡片底部补一句"今天共 N 节课 · 08:00 开始"把留白收住。

**3. 写 Windows 批处理踩的坑**

- 文件必须是 **CRLF** 换行，LF 的 `for (...)` 语句块会让 `cmd.exe` 解析失败且不报错。
- `cmd.exe` 不做通配符展开，`javac src\studyDesk\*.java` 在部分环境里不会编译任何文件；改成先 `for %%f in (...) do echo %%f > sources.txt`，再用 `javac @sources.txt`。
- `echo Build OK -> %~dp0xx.jar` 里的 `>` 会被当成重定向，把刚打好的 jar 覆盖成 13 字节的文本文件——命令行里的 `>` 该转义就转义。

## 八、v0.2.2：让项目在 IntelliJ IDEA 里"打开即运行"

反馈是在 IDEA 里打不开、跑不起来。排查后确认**不是代码问题，是工程缺失**：
仓库里没有任何 `.idea` / `*.iml` / `pom.xml` / `build.gradle`，
IDEA 打开裸目录时不会把 `src` 识别为源码根，于是所有类标红、主类旁边没有绿色三角。

### 1. 补上的工程配置

| 文件 | 作用 |
| --- | --- |
| `StudyDesk.iml` | 模块描述：`src` 标记为源码根，输出到 `out/production/StudyDesk` |
| `.idea/misc.xml` | 项目 SDK 与语言级别（`JDK_11`） |
| `.idea/modules.xml` | 模块登记 |
| `.idea/encodings.xml` | 全局强制 UTF-8，避免中文注释乱码 |
| `.idea/compiler.xml` | 目标字节码级别 11 |
| `.idea/runConfigurations/StudyDesk.xml` | 预置运行配置，入口 `studyDesk.StudyDeskApp` |
| `.editorconfig` | 编码 / 缩进 / 换行规则，IDEA 自动读取 |

同时修掉了 `.gitignore` 里的一个坑：原来写的是 `.idea/` 和 `*.iml` 整目录忽略，
这样即使本地配好了工程，push 上去别人 clone 下来还是一样跑不起来。
现在只忽略个人状态文件（`workspace.xml`、`shelf/`、`usage.statistics.xml` 等），工程配置正常入库。

### 2. 统一代码格式

检查发现 30 个源文件里 **15 个是 CRLF、15 个是 LF**，换行符混用。
这是"代码格式有问题"的真实来源：Git diff 会整文件标红，IDEA 里行尾也会显示不一致。

处理结果：

- 全部统一为 **UTF-8 无 BOM + LF**；
- 制表符统一为 4 空格（原本就没有 Tab）；
- 去掉行尾空白，文件末尾保留单个换行；
- `import` 按包名字母序重排（17 个文件因此调整），并清理未引用导入（实际为 0 个，说明原本没有冗余导入）；
- 7 个继承 Swing 组件的类补齐 `serialVersionUID`，消除 `-Xlint:serial` 警告。

### 3. 验证

- `javac -encoding UTF-8 -d out src/studyDesk/*.java` 零错误零警告（除 Swing 固有的 `this-escape` 提示）；
- `javac --release 11` 同样通过，证明代码只用到 JDK 11 的 API（`String.isBlank()` 是最高要求），没有依赖更高版本的语法；
- 按 IDEA 的输出路径 `out/production/StudyDesk` 编译验证通过；
- 启动进程截屏确认「今日面板」正常渲染，与之前的截图一致。

### 4. 别让格式"改了又退回去"

改完格式随手 commit，下次 checkout 发现源码又变回 CRLF —— 这是 Windows 上 `core.autocrlf=true` 的默认行为。
所以补了 `.gitattributes`：

```
*.java     text eol=lf
*.bat      text eol=crlf
*.jar      binary
*.png      binary
```

`git check-attr eol -- src/studyDesk/Store.java build.bat` 可以验证规则已生效
（源码 `lf`、批处理 `crlf`）。有了这一层，格式才真正稳定下来。
